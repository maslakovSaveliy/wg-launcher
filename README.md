# wg-launcher

Open-source desktop library and launcher for web games (JavaScript, WebAssembly, WebGL, WebGPU):
add a game by URL, run it in its own window with an isolated persistent session, and back up / restore its saves.

**Status:** Phase 0 — specifications, tooling and runtime evaluation. There is no usable client yet.
